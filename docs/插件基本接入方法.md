# 插件基本接入方法

- version: 0.2

## 前瞻适配声明

> 本文档描述的是 SuperAutoIsland 前瞻（dev）版本的积木注册 API（v2）。

进行前瞻适配需要安装 **SuperAutoIsland.Interface 0.3.9-dev.1**。

自 SAI.I 0.3.9-dev.1 起，积木注册全面改为 v2 接口。
`RegisterData`、`RegisterWrapper`、`RegisterActionHandler`、`RegisterRuleHandler`、`RegisterDataHandler`
等旧 API 均不可用，仅旧版本 SAI 支持；v2 接口只在 ClassIsland 2.2 版本出现。 
wrapper 与自定义 handler 统一改为继承积木基类实现（见下文「积木注册的两种方法」）。

## 接入基本方法

1. 在 Plugin.cs 添加函数：

    ```csharp
    using ClassIsland.Core.Abstractions.Services;
    
    public static bool IsPluginInstalled(string pkgName) {
        return IPluginService.LoadedPlugins.Any(info => info.Manifest.Id == pkgName);
    }
    ```

2. Initialize 添加如下内容：

    ```csharp
    if (IsPluginInstalled("lrs2187.sai")) {
        AppBase.Current.AppStarted += (_, _) => {
            var saiServerService = IAppHost.GetService<ISaiServer>();
            
            // 注册积木
            saiServerService.RegisterBlocks("ExamplePlugin", it => it
                .AddLabel("示例分组")
                .AddBlock(new BlockMetadata("example.actions.example")
                {
                    Kind = BlockKind.Action,
                    Name = "示例积木",
                    Fields = new Dictionary<string, Field>
                    {
                        ["ExampleString"] = BasicFields.Text("示例字符串字段")
                    }
                })
            );
        };
    }
    ```

3. 大功告成

## 积木注册的两种方法

积木注册只有两种写法，按需选择即可。

### 方法一：直接使用 BlockMetadata（适用于不变 port）

> 适用：只是现有行动和规则的不变 port——积木和某个已存在的 ClassIsland 行动/规则一一对应，不改行为、不加包装。

这种写法直接干 `BlockMetadata` 就行，无需任何额外代码。运行时没有对应的积木基类时，
行动会直接走 ClassIsland 原行动处理，规则会直接走 ClassIsland 原规则判断：

```csharp
using ClassIsland.Core.Icons;
using SuperAutoIsland.Interface.Metadata;

saiServerService.RegisterBlocks("ExamplePlugin", it => it
    .AddLabel("示例分组")
    .AddBlock(new BlockMetadata("example.actions.example")
    {
        Kind = BlockKind.Action,
        Name = "示例积木",
        Icon = ("方块", FluentIcons.SettingsRegular),
        Fields = new Dictionary<string, Field>
        {
            ["_dummy"] = BasicFields.Dummy("示例字符串区域"),
            ["ExampleString"] = BasicFields.Text("示例字符串字段"),
            ["ExampleNumber"] = BasicFields.Number("示例数字字段"),
            ["ExampleBoolean"] = BasicFields.Boolean("示例布尔值字段"),
            ["ExampleCheckbox"] = BasicFields.CheckBox("示例复选框字段", true),
            ["ExampleDropdown"] = BasicFields.Dropdown("示例下拉框字段", [
                ("字符串1", "值 val1"),
                ("字符串2", "值 val2")
            ]),
            ["ExampleDynamicDropdown"] = BasicFields.DynamicDropdown("示例动态下拉框字段", "my.actions.example.options"),
            ["ExampleDictionary"] = BasicFields.Dictionary("示例字典字段")
        }
    })
);
```

### 字典字段

`BasicFields.Dictionary` 声明一个字典输入字段，前端由用户插入字典积木组成任意键值对（可增删，键为字符串）。

该字段的值传入 C# 后为 JSON 对象，`actionItem.Settings` 实际类型为 `System.Text.Json.JsonElement`，直接用 `GetProperty` 访问：

```csharp
// Handler / Wrapper 中读取字典字段
if (actionItem.Settings is JsonElement settings)
{
    var name = settings
        .GetProperty("ExampleDictionary")
        .GetProperty("name")
        .GetString();  // 前端字典积木里填的键值
}
```

> 注意：
> 
> 数据块不能只用 `BlockMetadata` 注册。
> 运行时数据积木需要 `DataBlockBase` 提供 `SettingsType` 反序列化与 `Handler`，否则一律返回 `???`。
> 数据块请看方法二。

### 方法二：继承 xxxBlockBase 并重写（适用于 wrapper / 自定义 handler）

> 适用：有 wrapper（不同形状的积木转换为同一 ClassIsland 行动/规则，或者改 Settings 之类的）或自定义 handler（处理逻辑需要特调）。

继承对应的积木基类然后重写就行，注册时用 `AddBlock<T>()`（`T : BlockBase, new()`），元信息会自动从类中读取：

| 积木类型 | 基类              | 可重写成员                                   |
|----------|-------------------|----------------------------------------------|
| 行动     | `ActionBlockBase` | `Wrapper(ActionItem)`、`Handler(ActionItem)` |
| 规则     | `RuleBlockBase`   | `Wrapper(Rule)`、`Handler(Rule)`             |
| 数据     | `DataBlockBase`   | `SettingsType`、`Handler(object? data)`      |

字段在 `GetFields(FieldsRegister it)` 里声明。行动示例（wrapper 写法参考应用内 `RunActionProgramWrapper` 的对应场景）：

```csharp
using System.Text.Json;
using ClassIsland.Core.Icons;
using ClassIsland.Shared.Models.Automation;
using SuperAutoIsland.Interface.Metadata;
using SuperAutoIsland.Interface.Services;
using SuperAutoIsland.Interface.Services.Automations;

/// <summary>
/// 「运行应用程序」积木设置
/// </summary>
public partial class RunProgramSettings : ObservableRecipient { /* ... */ }

public class RunProgramBlock : ActionBlockBase
{
    public override string Id => "example.actions.runProgram";
    public override string Name => "运行应用程序";
    public override (string, string) Icon => ("程序", FluentIcons.SettingsRegular);

    public override void GetFields(FieldsRegister it) => it
        .AddField("Path", BasicFields.Text("程序路径"));

    // 包装：把积木的 Settings 转换为 classisland.os.run 行动的 Settings
    public override ActionItem Wrapper(ActionItem actionItem)
    {
        var settingsJson = JsonSerializer.Serialize(actionItem.Settings);
        var settings = JsonSerializer.Deserialize<RunProgramSettings>(settingsJson)!;
        settings.RunType = RunProgramSettings.RunActionRunType.Application;
        settingsJson = JsonSerializer.Serialize(settings);

        return new ActionItem
        {
            Id = "classisland.os.run",
            Settings = JsonSerializer.Deserialize<object>(settingsJson)
        };
    }

    // 自定义 handler 则重写 Handler（行动 Handler 在 ui 线程运行，规则 Handler 不一定）
    // public override async Task Handler(ActionItem actionItem) { /* ... */ }
}
```

数据块一定要用 `DataBlockBase`（写法参考应用内 `GetDynamicTextBlock.cs` / `TextDialogBlock.cs`）：

```csharp
public class ExampleDataBlock : DataBlockBase
{
    public override string Id => "my.data.example";
    public override string Name => "示例数据块";
    public override (string, string) Icon => ("数据", FluentIcons.SettingsRegular);
    public override string DataOutput => "String";  // 数据块的输出结果，用于前端 Blockly 类型检查。使用 js 类型名称
    public override Type SettingsType => typeof(ExampleDataSettings);  // 数据块参数的反序列化类型

    public override void GetFields(FieldsRegister it) => it
        .AddField("ExampleString", BasicFields.Text("示例字符串字段"));

    public override async Task<object> Handler(object? data)
    {
        if (data is not ExampleDataSettings settings)
            return "???";
        return settings.ExampleString;  // 返回值作为数据积木的输出
    }
}
```

注册（两种方法统一走 `RegisterBlocks`）：

```csharp
saiServerService.RegisterBlocks("ExamplePlugin", it => it
    .AddLabel("示例分组")
    .AddBlock<RunProgramBlock>()
    .AddBlock<ExampleDataBlock>()
);
```

> 注意：
> 
> 注册时若有相同 CategoryName（RegisterBlocks 的第一个参数），会直接覆盖原 Category！

## 动态下拉框注册

> 用于在前端加载时获取下拉框内容，而非初始化时的固定内容

位于 `ISaiServer.RegisterDynamicDropdown`，下方为定义：

```csharp
/// <summary>
/// 动态下拉框处理器
/// </summary>
public delegate Task<List<(string, string)>> DynamicDropdownHandler();

/// <summary>
/// 注册动态下拉框 getter
/// </summary>
/// <param name="id">动态下拉框 id</param>
/// <param name="handler">获取函数</param>
public void RegisterDynamicDropdown(string id, DynamicDropdownHandler handler);
```

下方为示例

```csharp
saiServerService.RegisterDynamicDropdown("my.actions.example.options", async () =>
    [("???", "???")]);
```
