## 功能

- 复用 ClassIsland 工作流内容：
  - **可复用的行动组**：将常用行动打包成组，多处调用，一改全改。
  - **可复用的规则集**：把复杂的规则集保存下来，随时复用。

- Blockly 内容：
  - **Blockly 行动**：通过拖拽积木块来构建自动化行动，轻松实现复杂流程。

    > 支持触发行动、判定规则、获取数据。甚至还可以启用档案操作！去组合属于你自己的更高级、好玩的工作流吧。
